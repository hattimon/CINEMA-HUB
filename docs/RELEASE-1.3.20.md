# Cinema Hub 1.3.20 – automatyczne przygotowanie playlist

- Playlisty mogą automatycznie dopasowywać pozycje do dostępnych filmów i odcinków oraz rozpoczynać albo wznawiać odtwarzanie.
- Otwarcie istniejącej playlisty uzupełnia brakujące filmy i dokładne odnośniki do odcinków. Cinema Hub zachowuje kolejność, zapisane miejsce i postęp.
- Odtwarzacz wybiera hosting zgodnie z dotychczasowymi preferencjami i po zakończeniu uruchamia następną pozycję. Jeżeli Filman wymaga zalogowania, można ponowić całe dopasowanie jednym przyciskiem po przejściu weryfikacji.

Zaktualizuj obraz `ghcr.io/hattimon/cinema-hub:1.3.20` w DCC albo w istniejącym projekcie Compose. Wydanie obsługuje Windows z Docker Desktop oraz Linuksa na amd64 i ARM64.
