# Cinema Hub 1.3.17 – logowanie i okładki Filmana

- Ręczne logowanie Filmana otwiera formularz w zwykłym Chromium. Przycisk **Zakończ i zachowaj sesję** zamyka okno i zapisuje profil.
- Okładki Filmana korzystają z zapisanej sesji Chromium. Cloudflare odrzucał wcześniejsze żądania obrazów kodem HTTP 403.
- Obraz `ghcr.io/hattimon/cinema-hub:1.3.17` jest przeznaczony dla `linux/amd64` i `linux/arm64`. DCC wskazuje tę wersję po odświeżeniu katalogu. [Instrukcja aktualizacji](https://github.com/hattimon/CINEMA-HUB/blob/v1.3.17/docs/INSTALL.md)
