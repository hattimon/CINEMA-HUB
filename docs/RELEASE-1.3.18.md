# Cinema Hub 1.3.18 – automatyczny zapis sesji Filmana

- Po wykryciu zalogowanego konta Cinema Hub zapisuje profil Chromium i zamyka okno logowania. Główne okno może odświeżyć katalog bez klikania „Zakończ i zachowaj sesję”.
- Katalog, odtwarzanie i okładki korzystają z tego samego trybu Chromium co ręczne logowanie. Cinema Hub ponawia krótkotrwałe błędy dostępu i pokazuje osobne komunikaty dla formularza logowania i weryfikacji.
- DCC Container Updater 1.1.9 udostępnia aktualizację projektów Compose z Windows przy wierszu Cinema Hub. Procedura PowerShell robi kopię bazy i testuje obraz na osobnych danych przed wdrożeniem.

Obraz serwera `ghcr.io/hattimon/cinema-hub:1.3.18` jest dostępny dla `linux/amd64` i `linux/arm64`. [Instalacja i aktualizacja](https://github.com/hattimon/CINEMA-HUB/blob/v1.3.18/docs/INSTALL.md)
